# 📖 Novelku Backend API

Dokumentasi utama dan panduan menjalankan aplikasi backend tersedia di [README Utama (Root Repository)](../README.md).

### Menjalankan Server Backend Secara Langsung:

```bash
# Pastikan database postgres di Docker sudah berjalan
docker compose up -d

# Jalankan server
go run cmd/api/main.go
```
